# Unified Novi Sad planning model

The Novi Sad command now produces one electrical model. The same inferred
topology is used for the pandapower network, interactive map, power-flow
results, and validation report. The upstream repository's three-source
demonstrator is no longer part of this command.

## Run the workflow

From the repository root on Windows:

```powershell
.\.venv\Scripts\python.exe scripts\run_novi_sad.py
```

The normal run reuses the local cached OSM study data in `data/cache/data.pkl`, then
deterministically regenerates the synthetic demand inventory, capacity-balanced
feeder assignments, unified network, map, and validation reports. It also writes
`data/novi_sad/reference/generated/novi_sad_input_manifest.json` with hashes of the cache and configuration plus
the relevant package versions.

Use the optional flags when needed:

```powershell
# Download and rebuild the OSM polygon, land use, and street graph first.
.\.venv\Scripts\python.exe scripts\run_novi_sad.py --refresh-osm

# Faster engineering iterations that leave the existing map and reports unchanged.
.\.venv\Scripts\python.exe scripts\run_novi_sad.py --skip-map --skip-validation
```

`--refresh-osm` requires network access and may change the generated topology as
OpenStreetMap changes. A cached run is repeatable on the same local snapshot,
but `data/cache/data.pkl` is gitignored, so a fresh clone is not bit-for-bit reproducible.
The input manifest provides traceability; it does not replace a versioned source
snapshot.

## Model structure

The unified network contains all nine EDS-listed primary stations for the Novi
Sad branch:

- NS1, NS5, NS6, NS7, NS9, Rimski Sancevi, and Futog deliver at 20 kV through
  modelled 110/20-kV transformers.
- NS2 and NS4 deliver through 110/35-kV transformers, inferred 35-kV routes, and
  six EDS-listed 35/10-kV stations: Liman, Centar, Podbara, Sever, Industrijska,
  and Telep.

NS2-Centar and NS4-Liman are documented upstream associations. The remaining
four legacy associations use the closest plausible primary on the road graph
and are explicitly labelled as inferred.

The demand layer contains 2,648 unique synthetic service points. Their annual
energy sums to the supplied 2025 value of 1,147,635 MWh. The 214.854-MW peak is
derived from annual energy with an assumed 1.64 peak-to-mean ratio; it is not a
measured system peak. EDS Pmax values are soft allocation targets, while station
ratings and an 86% allocation margin are hard routing limits. The solved base
case must remain below 90% transformer loading, allowing a small allowance for
losses and reactive power beyond the allocation calculation.

Only NS5, NS7, and Rimski Sancevi have name-confirmed OSM coordinates. Other
station locations, street feeder routes, cable parameters, and most upstream
associations are planning assumptions. This is a scenario model, not an as-built
utility model or a feeder-level digital twin.

## Outputs

- `artifacts/novi_sad/reference/models/ppnet_novi_sad.json`: unified pandapower network.
- `artifacts/novi_sad/reference/models/novi_sad_powerflow_results.json`: compact solved-case metrics.
- `artifacts/novi_sad/reference/models/novi_sad_model_manifest.json`: traceability and assumptions for stations and
  all synthetic loads.
- `data/novi_sad/reference/generated/novi_sad_input_manifest.json`: hash and dependency metadata for the local
  cached OSM-derived input snapshot.
- `artifacts/novi_sad/reference/maps/novi_sad_simulation_map.html`: interactive view of the same inferred
  topology.
- `artifacts/novi_sad/reference/reports/novi_sad_validation_report.json` and `.md`: acceptance checks and stress-test
  result.
- `data/novi_sad/reference/generated/novi_sad_synthetic_transformers.csv`: calibrated synthetic demand inventory.
- `data/novi_sad/reference/generated/novi_sad_synthetic_feeder_assignments.csv`: delivery-root and primary-source
  assignment for every demand point.

The internal-consistency gate requires a converged power flow, exactly 2,648
traceable loads, nine radial source islands with one active primary each, the
NS2/NS4 legacy voltage path, all loads electrically supplied, voltages within
0.95-1.05 pu, line loading below 100%, transformer loading below the 90%
planning margin, and non-negative losses below 10%. Calibrated energy and peak
assertions are reported separately and do not contribute to the pass status.

The generated pandapower buses and lines carry the same inferred street and
station-connector geodata used by the map. Long connectors such as the Futog
catchment therefore contribute electrical impedance rather than being visual
lines only.

Official planning source: [EDS Plan razvoja distributivnog sistema
2025-2034](https://elektrodistribucija.rs/regulativa/propisi/dokumenta/Plan_razvoja_2025_2034.pdf).
